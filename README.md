# User Management System

### A Web Application which helps to manage users based on their roles. It follows the rule of RBAC.

## Tech Stack
- Frontend
    <ol type="1">
        <li>React + Vite</li>
        <li>Typescript</li>
        <li>Tailwindcss</li>
    </ol>
- Backend
    <ol type="1">
        <li>Node.js + Express</li>
        <li>Typescript</li>
        <li>bcryptjs - hashing</li>
        <li>jsonwebtoken - sessions</li>
    </ol>
- Database
    <ol type="1">
        <li>MongoDB Atlas (Cloud)</li>
    <ol>
